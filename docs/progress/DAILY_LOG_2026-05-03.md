### 3) WeatherDataFormatterUtil 확장
- **parseKmaResponse 메서드 구현**: 기상청 API 응답(JSON)을 WeatherData 엔티티로 변환
  - 기온(`T1H`, `TMP`) → `temperature`
  - 습도(`REH`) → `humidity`
  - 운량(`SKY` 1~4) → `cloudCover` (0.0~1.0으로 정규화)
  - 일사량 → `irradiance` (기본값 0.0)
- **예외 처리**: BusinessException으로 통일, JSON 파싱 오류 감지
- **로깅**: 파싱 성공/실패 상태 명확한 로그 추가
