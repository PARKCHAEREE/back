#### 2-1) 기존 문제점

#### 2-2) 현재 해결책 (@Transactional 방식)
```java
@Service
@Transactional
public class WeatherDataImportService {
    public void importCsvData(Long plantId, MultipartFile file) {
        // Step 1: 기존 데이터 삭제 (DELETE FROM plant_feature_logs WHERE power_plant_id = ?)
        plantFeatureLogRepository.deleteByPowerPlantId(plantId);
        
        // Step 2: 새 데이터 저장 (한 번의 트랜잭션으로 처리)
        List<PlantFeatureLog> logs = parseCsv(file);
        plantFeatureLogRepository.saveAll(logs);
    }
}
```
