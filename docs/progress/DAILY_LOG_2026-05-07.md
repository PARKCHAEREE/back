## 🌐 API 엔드포인트 확정

### CSV 데이터
- `POST /api/v1/plants/{plantId}/weather/upload-advisor-csv`
  - 파라미터: file (MultipartFile), enableDemoCheat (boolean)
  - 설명: AI 팀 전처리 CSV 업로드 및 임포트

### 시뮬레이션 제어 (신규) ✨
- `GET /api/v1/simulation/time`
  - 반환: 현재 가상 시간 (LocalDateTime)
  
- `POST /api/v1/simulation/tick`
  - 설명: 가상 시간을 1시간 진행
  - 반환: 업데이트된 가상 시간
  
- `POST /api/v1/simulation/trigger-drone-error`
  - 설명: 드론 오류 트리거 (다음 이미지 분석 시 파손된 이미지 전송)
  - 반환: 성공 메시지

### 대시보드 통합 포인트
- 모든 대시보드/측정 API의 `timestamp`, `measuredAt` 등 시간 필드는 가상 시간 기준
- 프론트에서 실시간 진행: `/tick` API 주기적 호출 또는 백엔드 @Scheduled 자동 진행 선택

## 📝 아키텍처 요약

### 데이터 흐름
```
[CSV 파일] (AI 팀 전처리)
    ↓
[POST /upload-advisor-csv]
    ↓
[WeatherDataImportService]
    ↓
[EnergyLog + WeatherData] (DB 저장)
    ↓
[SimulationService.getVirtualCurrentTime()]
    ↓
[모든 로직이 가상 시간 기준으로 동작]
```

- 🎮 **수동 제어**: `/tick` API로 원할 때마다 진행
