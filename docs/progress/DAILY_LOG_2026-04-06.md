### 1. 공통 응답 포맷 구현

모든 API 응답이 아래 형식을 따르도록 공통 DTO를 추가했습니다.

**성공 응답**
```json
{ "success": true, "data": {}, "message": "..." }
```

**실패 응답**
```json
{ "success": false, "error": { "code": "...", "message": "...", "details": null } }
```

- `dto/ApiResponse.java` - 성공 응답 래퍼
- `dto/ApiErrorResponse.java` - 에러 응답 래퍼
- `exception/GlobalExceptionHandler.java` - 전역 예외 처리기 보강

### 2. Phase 1 완료: 인증 API + 발전소 조회 API

#### 인증 관련 (API 명세 기준)
| Method | Path | 설명 | 파일 |
|--------|------|------|------|
| POST | `/api/v1/auth/signup` | 회원가입 | `AuthController`, `AuthService` |
| POST | `/api/v1/auth/login` | 로그인 (JWT 발급) | `AuthController`, `AuthService` |
| POST | `/api/v1/auth/logout` | 로그아웃 | `AuthController` |
| GET  | `/api/v1/users/me` | 내 정보 조회 | `UserController` |

신규 DTO:
- `SignupRequest.java` - 회원가입 요청
- `UserResponse.java` - 사용자 정보 응답
- `LoginResponse.java` - 로그인 응답 (accessToken, refreshToken, user 포함)

#### 발전소 조회 관련
| Method | Path | 설명 | 파일 |
|--------|------|------|------|
| GET | `/api/v1/plants` | 발전소 목록 조회 | `PlantController`, `PlantService` |
| GET | `/api/v1/plants/{plantId}` | 발전소 상세 조회 | `PlantController`, `PlantService` |

신규 파일:
- `controller/PlantController.java`
- `service/PlantService.java`
- `dto/PlantResponse.java`

### 5. 실행 환경 분리 (Swagger 확인 가능하도록)

문제: 기존에는 MySQL 연결 없이 실행 불가 → 오류 발생  
해결: 프로필 기반 DB 분리

| 프로필 | 실행 명령어 | DB | 목적 |
|--------|------------|-----|------|
| `swagger` (기본) | `./gradlew bootRun` | H2 메모리 | 개발 확인, Swagger 테스트 |
| `mysql` | `./gradlew bootRun --args="--spring.profiles.active=mysql"` | 로컬 MySQL | 실제 데이터 연동 |

변경 파일:
- `application.properties` - 기본 프로필을 `swagger`로 지정
- `application-swagger.properties` - H2 설정 + Swagger 활성화
- `application-mysql.properties.example` - 팀원 공유용 MySQL 설정 템플릿 (신규)

**Swagger 접속**: `http://localhost:8080/swagger-ui.html`  
**H2 콘솔 접속**: `http://localhost:8080/h2-console`

## ⚙️ 채리씨 로컬 세팅 방법

```powershell
# 1. 최신 코드 받기
git pull origin feature/auth-system

# 2. MySQL 설정 파일 생성
copy src\main\resources\application-mysql.properties.example `
     src\main\resources\application-mysql.properties
# → 파일 열어서 YOUR_MYSQL_PASSWORD를 본인 비밀번호로 수정

# 3. MySQL에서 DB 생성 (최초 1회)
# mysql -u root -p
# > CREATE DATABASE solarwise CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 4. MySQL로 실행
.\gradlew.bat bootRun --args="--spring.profiles.active=mysql"

# 또는 Swagger만 보려면 (MySQL 없이도 됨)
.\gradlew.bat bootRun
# → http://localhost:8080/swagger-ui.html
```
