### 1) VisionAnomalyTriggerRequest DTO 생성 (신규)

#### 1-1) DTO 필드 구조
```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class VisionAnomalyTriggerRequest {
    private Long plantId;                  // 발전소 ID
    private String anomalyType;            // 이상 유형 (CRACK, DIRT, NORMAL)
    private Double confidence;             // 신뢰도 (0.0 ~ 1.0)
    private String imageUrl;               // 이미지 URL (S3 또는 외부 저장소)
    private String xaiExplanation;         // XAI 분석 결과 설명
}
```

**필드 설명:**
- `plantId`: 발전소 ID (필수) - 트리거 대상 발전소
- `anomalyType`: 이상 유형 (필수) - CRACK(균열), DIRT(오염/먼지), NORMAL(정상)
- `confidence`: 신뢰도 (필수) - YOLOv11s 모델 예측 신뢰도 (0~1 범위)
- `imageUrl`: 이미지 URL (선택) - RDS 용량 제한으로 URL 형태로 저장
- `xaiExplanation`: XAI 분석 설명 (필수) - 판별 근거 텍스트

#### 1-2) 위치
- `src/main/java/com/solarwise/capstonebackend/dto/VisionAnomalyTriggerRequest.java`

#### 2-2) 구현 로직

**Step 1: 발전소 조회**
```java
PowerPlant plant = powerPlantRepository.findById(request.getPlantId())
        .orElseThrow(() -> new IllegalArgumentException("발전소를 찾을 수 없습니다. ID: " + request.getPlantId()));
```

**Step 2: 가상 시간 조회 (중요!)**
```java
LocalDateTime now = getVirtualCurrentTime();
```

**Step 3: 신뢰도 기반 심각도 결정 (자동화)**
```java
// confidence >= 0.9 → HIGH 경고 (높은 신뢰도)
// confidence < 0.9 → MEDIUM 경고 (중간 신뢰도)
String severity = (request.getConfidence() != null && request.getConfidence() >= 0.9) 
                  ? "HIGH" 
                  : "MEDIUM";
```

**Step 4: Anomaly 엔티티 생성**
```java
Anomaly anomaly = Anomaly.builder()
        .powerPlant(plant)
        .type("VISION")                    // 유형: 비전 이상
        .summary("시뮬레이션 트리거: 비전 이상")
        .description(request.getXaiExplanation())
        .severity(severity)                // 자동 결정된 심각도
        .cause(String.format("유형: %s, 신뢰도: %.2f", 
               request.getAnomalyType(), 
               request.getConfidence() == null ? 0.0 : request.getConfidence()))
        .recommendedAction(null)
        .status("OPEN")                    // 상태: 미처리
        .detectedAt(now)                   // 가상 시간 사용
        .createdAt(now)
        .updatedAt(now)
        .build();

Anomaly saved = anomalyRepository.save(anomaly);
```

**Step 5: VisionAnalysis 엔티티 생성 (이미지 분석 결과 저장)**
```java
VisionAnalysis visionAnalysis = VisionAnalysis.builder()
        .anomaly(saved)
        .imageUrl(request.getImageUrl())   // URL 저장 (원본 이미지 금지)
        .analysisResult(String.format("type:%s, confidence:%.2f, xai:%s",
                request.getAnomalyType(), 
                request.getConfidence() == null ? 0.0 : request.getConfidence(),
                request.getXaiExplanation()))
        .createdAt(now)
        .build();

visionAnalysisRepository.save(visionAnalysis);
```

**Step 6: 이메일 알림 발송 (비동기)**
```java
// confidence >= 0.9 (HIGH)인 경우만 이메일 발송 (NotificationService 내부 처리)
String ownerEmail = plant.getUser().getEmail();
notificationService.sendAnomalyAlert(saved, ownerEmail);
```
