#### 1.1 @Async 리턴 타입 변경 ✅
모든 외부 API 호출 메서드를 `CompletableFuture<T>` 기반으로 마이그레이션:

| 메서드 | 변경 전 | 변경 후 |
|--------|---------|---------|
| `requestPredictionFromAi` | `AiPredictionResponse` | `CompletableFuture<AiPredictionResponse>` |
| `requestXaiExplanation` | `XaiExplanationResponse` | `CompletableFuture<XaiExplanationResponse>` |
| `detectPowerAnomaly` | `PowerAnomalyDetectionResponse` | `CompletableFuture<PowerAnomalyDetectionResponse>` |
| `detectVisionAnomaly` | `VisionAnomalyDetectionResponse` | `CompletableFuture<VisionAnomalyDetectionResponse>` |

**기술 세부사항:**
```java
@Async
public CompletableFuture<AiPredictionResponse> requestPredictionFromAi(...) {
    // ... 처리 로직
    return CompletableFuture.completedFuture(response);
}
```

- `ForecastController.java` 수정
- `CompletableFuture.join()` 을 사용하여 동기 응답 대기
- API 클라이언트가 원활하게 응답받도록 처리

```java

AiPredictionResponse response = future.join(); // 동기적 대기
return ResponseEntity.ok(ApiResponse.success(response));
```

## 🏗️ 아키텍처 개선사항

### 비동기 처리 흐름
```
클라이언트 요청
    ↓
ForecastController
    ↓
@Async AiIntegrationService
    ├─→ AI 서버 호출 (비블로킹)
    ├─→ 응답 수신
    ├─→ 엔티티로 변환
    ├─→ DB 저장 (ForecastRepository)
    └─→ CompletableFuture.completedFuture(response)
    ↓
Controller.join() (동기 대기)
    ↓
클라이언트에 응답 반환
```

### 명세서 준수
- ✅ AI 예측 API: `/internal/forecast/predict`
- ✅ XAI 설명 API: `/internal/xai/explain` (명세서 6-4)
- ✅ 이상 탐지: `/internal/anomaly/power-detect`, `/internal/anomaly/vision-detect`
