## ✅ 오늘 완료된 작업 요약

### 1. AI 서버 연동 클라이언트 구현

`RestTemplate`을 사용하여 Python AI 서버와 통신하는 핵심 로직을 구현했습니다.

| 파일 | 변경 내용 |
|---|---|
| `service/AiIntegrationService.java` | 발전량 예측(`predict`), 예측 설명(`explain`) API 호출 로직 추가 |
| `application.properties` | `ai.server.base-url` 속성을 추가하여 AI 서버 주소 관리 |

### 2. AI 예측/설명 API 엔드포인트 개발

프론트엔드에서 실시간 발전량 예측치와 그 근거(XAI)를 조회할 수 있는 API를 개발했습니다.

| Method | Path | 설명 | 파일 |
 |---|---|---|---|
| GET | `/api/v1/plants/{plantId}/forecasts` | AI 예측 발전량 조회 | `ForecastController` |
| GET | `/api/v1/plants/{plantId}/forecasts/explanations` | XAI 예측 설명 조회 | `ForecastController` |

신규 파일:
- `controller/ForecastController.java`
- `dto/ai/AiPredictionRequest.java`
- `dto/ai/AiPredictionResponse.java`
- `dto/ai/XaiExplanationResponse.java`
- `dto/ai/AiApiResponse.java` (AI 서버 공통 응답)

### 3. 과거 기상 데이터 CSV 대량 적재 기능 구현

AI 모델 학습에 필요한 대량의 과거 데이터를 CSV 파일로 업로드하여 DB에 저장하는 파이프라인을 구축했습니다.

| Method | Path | 설명 | 파일 |
 |---|---|---|---|
| POST | `/api/v1/plants/{plantId}/weather/upload-csv` | 과거 기상 데이터 CSV 업로드 | `WeatherController` |

신규 파일:
- `controller/WeatherController.java`

제가 구현한 AI 연동 API는 Swagger에서 바로 테스트해볼 수 있습니다.

 ```powershell
 # 1. 최신 코드 받기
 git pull origin feature/ai-integration
 
 # 2. Swagger로 실행 
 .\gradlew.bat bootRun
 ```

3.  `weather-controller`에서 `POST /api/v1/plants/{plantId}/weather/upload-csv`에 샘플 CSV 파일을 업로드하여 테스트
